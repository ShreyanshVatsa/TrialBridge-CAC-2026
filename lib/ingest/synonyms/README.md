# Synonym tables

Generated by `npm run synonyms` (scripts/ingest/synonyms.ts). Downloads are cached in `data/cache/synonyms-src/`.
Tables hold only genes, variants, drugs and cancer types that occur in our trial snapshot. Do not edit by hand.

| File | Content | Source | License |
| --- | --- | --- | --- |
| genes.json | cancer-gene symbol -> aliases | HGNC complete set (genenames.org), gene list from CIViC | CC0 1.0 |
| variants.json | gene + variant name -> aliases | CIViC variant summaries (civicdb.org) | CC0 1.0 |
| drugs.json | drug -> synonyms/brand names + drug classes | NCI Thesaurus (NCI EVS, Thesaurus.FLAT.zip) | NCIt terms of use (free, attribute NCI) |
| diseases.json | groups of equivalent cancer-type names | NCI Thesaurus | as above |

Drug classes are the NCIt parent concepts (generic parents removed), lightly normalized, for example pembrolizumab -> `anti-PD-1`.
OncoKB is deliberately not used (license). These tables are search aids, not clinical advice.
